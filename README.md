# Between the Lines — 字里行间

*A place where feelings find each other.*

**Between the Lines** is a bilingual creative community website where people can share artwork, music, and the personal stories behind them.

Every song has a story. Every artwork holds a feeling. Somewhere in the world, someone might feel the same way.

**字里行间** 是一个支持中英文切换的创意分享网站。人们可以在这里分享画作、音乐，以及作品背后的故事与情感。

---

## 🌙 About the Project | 项目介绍

Between the Lines was created around a simple idea: emotions connect people, even when they are strangers.

Through music, art, and personal stories, this website offers a space for people to express themselves and discover feelings they may have in common with others.

这个项目希望通过音乐、艺术和真实故事，让不同的人产生情感上的连接。即使彼此素不相识，也可能因为一首歌、一幅画或一个故事而感受到理解。

## ✨ Features | 主要功能

- **Bilingual Interface | 中英文切换**  
  Switch between English and Chinese.

- **Artwork Gallery | 画作画廊**  
  Share artwork, upload images, and tell the stories behind your creations.

- **Music Stories | 音乐故事**  
  Share meaningful songs, artists, and the memories or feelings connected to them.

- **Comments | 留言互动**  
  Leave thoughts and responses on shared music stories.

- **Artwork Details | 画作详情**  
  Open artwork to explore its story, creator, and reference information.

- **Responsive Design | 响应式设计**  
  A layout designed to work across different screen sizes.

## 🛠️ Technologies | 使用技术

- HTML5
- CSS3
- JavaScript
- Supabase

Supabase is used for data storage and artwork image uploads.

## 🚀 Getting Started | 如何运行

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure the Supabase client is configured with your own project settings.
4. Open `index.html` using a local development server, such as the VS Code Live Server extension.
5. Explore the website and try switching languages, sharing artwork, and browsing music stories.

### Supabase Setup

This project requires a Supabase project for its database and image storage features.

Before using the upload and sharing functions, configure the Supabase client and the required database tables and storage permissions.

Do not publish private service-role keys, passwords, or other secret credentials in a public repository.
